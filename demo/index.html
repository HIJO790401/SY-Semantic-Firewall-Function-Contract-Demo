先有主體，再有命令

誰定義命令、誰負責、依哪個版本和邊界執行、缺定義回誰、完成或失效如何停？自然語言可以由 Owner 定義、糾錯、驗收到閉環；函式將其固定成可執行規則。

主體定義與責任 → 版本條件 → 許可／執行 → 驗收／終止／回主體。不是自然語言對 JSON 或 skill 對函式，也不能只剩技術閘門。

這不是多寫幾句提示，而是將主體定義固定成模型可引用、執行端強制的版本函式，避免每次自行重解而偷換判準；失配就停止、回 Owner，不自行補義。

證據 → 判斷

固定同函式、參數、權限與驗收；先 permit，再真 JS，最後終態。兩模型各 8 項有效任務合格，另 4 項正確停止／交回。
